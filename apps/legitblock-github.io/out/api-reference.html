REST API Reference

Next.js LegitBlock REST API

Complete specification for all 17 REST API endpoints provided by apps/nextjs-legitblock, serving both the web application and the Ink CLI terminal client.

Authentication & LDAP

POST/api/auth/login

Authenticate username and password against LDAP directory; returns HTTP-only JWT session cookie.

Request Payload:
{ "username": "alice.chair", "password": "password123" }
Response Sample:
{ "success": true, "user": { "id": "alice.chair", "role": "Director", "displayName": "Alice Smith" } }
GET/api/auth/me

Get currently authenticated user session and role privileges.

Response Sample:
{ "authenticated": true, "user": { "id": "alice.chair", "role": "Director" } }
POST/api/auth/logout

Clears current user authentication session cookie.

Response Sample:
{ "success": true }

Blockchain & Ledger

GET/api/blockchain/status

Returns ledger height, genesis state, active proposals count, and cryptographic validity.

Response Sample:
{ "initialized": true, "blockCount": 5, "isValid": true, "difficulty": 2 }
GET/api/blockchain/blocks

Returns all blocks on the chain with index, timestamp, hashes, and transaction payloads.

Response Sample:
[ { "index": 0, "hash": "000a4...", "previousHash": "00000...", "nonce": 142 } ]
POST/api/blockchain/genesis

Initializes Genesis Block #0 and ratifies initial template founding documents.

Request Payload:
{ "templateId": "c_corp", "organizationName": "Acme Inc.", "jurisdiction": "Delaware" }
Response Sample:
{ "success": true, "genesisHash": "000a4...", "blocksCreated": 4 }
GET/api/blockchain/verify

Performs full cryptographic audit of all hashes and previousHash links across entire history.

Response Sample:
{ "valid": true, "totalBlocks": 5, "auditedAt": "2026-09-08T09:12:00Z" }

Documents & Diffing

GET/api/documents

Lists all currently active, ratified organizational documents on-chain.

Response Sample:
[ { "id": "doc-1", "title": "Articles of Incorporation", "version": "1.1", "category": "founding" } ]
GET/api/documents/[id]

Retrieves the complete Markdown content and ratification block history for a document.

Response Sample:
{ "id": "doc-1", "title": "Articles of Incorporation", "content": "# Articles...", "version": "1.1" }
POST/api/documents/[id]/diff

Computes unified git diff and structured line changes between active document and proposed text.

Request Payload:
{ "proposedContent": "# Articles of Incorporation\nNew clause..." }
Response Sample:
{ "unifiedDiff": "--- a\n+++ b\n...", "additions": 1, "deletions": 0 }

Proposals & Voting

GET/api/proposals

Lists all governance proposals with status, quorum thresholds, and ballot tallies.

Response Sample:
[ { "id": "prop-1", "title": "Amend Bylaws", "status": "VOTING", "yesVotes": 2, "required": 2 } ]
POST/api/proposals

Creates an amendment or new document proposal on-chain.

Request Payload:
{ "title": "Increase Option Pool", "documentId": "doc-1", "proposedContent": "...", "rule": "SUPERMAJORITY_TWO_THIRDS" }
Response Sample:
{ "success": true, "proposalId": "prop-2" }
POST/api/proposals/[id]/vote

Submits signed ballot. Triggers automatic block mining if vote reaches statutory quorum.

Request Payload:
{ "decision": "yes", "comment": "Approved per board consensus" }
Response Sample:
{ "success": true, "quorumReached": true, "minedBlock": 6 }
